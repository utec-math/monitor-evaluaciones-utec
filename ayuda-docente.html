Lo esencial, en una sola pantalla

El monitor organiza señales para facilitar la revisión. Ningún color ni evento determina por sí solo una irregularidad.

1Nueva sesión

2Configurá

3Compartí

Los estudiantes escriben el código en la aplicación instalada.

4Cerrá

Al finalizar, cerrá la sesión para impedir nuevas conexiones y subidas.

Cómo interpretar la información

Colores de las tarjetas

Verde: sin señales relevantes recientes.
Amarillo: hay un evento reciente para revisar.
Naranja: se acumularon varias señales en poco tiempo.
Rojo: prioridad alta si se incorpora una regla específica.

Controles sobre la aplicación

Inicio / Recargar: devuelve o actualiza la página autorizada.
Recuperar: intenta restablecer la navegación normal.
Desbloquear 2 min: permite navegación libre temporalmente por decisión docente.
Bloquear: termina el permiso temporal.
Finalizar: detiene esa aplicación de evaluación.
Importante: una desconexión, un cambio de aplicación o un clip son elementos para revisión humana. El monitor no sanciona ni concluye automáticamente que hubo copia.
